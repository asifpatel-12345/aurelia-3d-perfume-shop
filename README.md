# 🌸 Aurelia - 3D Perfume Shop

A luxury perfume shop website with an interactive 3D rotating bottle, built using **HTML, CSS, JavaScript and Three.js**.

🔗 **Live Demo:** https://YOUR-USERNAME.github.io/aurelia-3d-perfume-shop/

## ✨ Features

- Interactive 3D glass perfume bottle (drag or swipe to rotate)
- Scent selector that changes the bottle's liquid color in real time
- Product collection with "View in 3D" and "Add to Cart" buttons
- Live cart counter
- Floating gold sparkle particles
- Dark and gold luxury theme
- Fully responsive (desktop and mobile)

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- [Three.js](https://threejs.org/) (r128, loaded via CDN)

## 🚀 How to Run

1. Clone the repository
```bash
   git clone https://github.com/YOUR-USERNAME/aurelia-3d-perfume-shop.git
```
2. Open the folder in VS Code
3. Install the **Live Server** extension
4. Right click `index.html` and choose **Open with Live Server**

> An internet connection is required because Three.js and Google Fonts load from a CDN.

## 🎮 How to Use

- **Drag** the bottle with mouse or finger to rotate it
- **Click a color circle** to change the scent
- Click **View in 3D** on any product card to preview it
- Click **Add to Cart** to increase the cart count
